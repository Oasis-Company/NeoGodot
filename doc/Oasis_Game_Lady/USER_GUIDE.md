# NeoGodot AI User Guide

## Introduction

Welcome to the NeoGodot AI plugin! This guide will help you get started with AI-powered game development in Godot.

---

## 1. Installation

### 1.1 Install Gateway Service

```bash
cd runtime/neo_runtime_gateway
poetry install
cp .env.example .env
```

Edit `.env` and configure your Qwen API key:
```env
QWEN_API_KEY=your_api_key_here
```

Start the gateway:
```bash
poetry run python main.py
```

### 1.2 Install Godot Plugin

1. Copy `addons/neo_ai/` to your project's `res://addons/` directory
2. Open your Godot project
3. Go to `Project > Project Settings > Plugins`
4. Enable the "Neo AI" plugin

---

## 2. Quick Start

### 2.1 Open the AI Dock

1. Go to `View > Neo AI`
2. The dock will appear on the right side of the editor

### 2.2 Create Your First Plan

1. Click **Generate Plan** in the dock
2. Enter your goal (e.g., "Create a 2D platformer character")
3. Click **Generate**

The system will:
- Create a task DAG
- Show you the plan in the Main Screen
- Ask any clarifying questions

### 2.3 Execute Tasks

1. Click **Full View** to open the Main Screen
2. Select a task from the plan tree
3. Click **Run** to execute

---

## 3. Using the AI Dock

### 3.1 Status Bar

- **Goal**: Shows your current objective
- **Mode**: Switch between Shadow/Guardian/Collaborative modes
- **Phase**: Progress indicator (Plan → Code → Assets → Import)

### 3.2 Budget Bar

Displays your budget usage:
- Green: Under 70%
- Yellow: 70-90%
- Red: Over 90%

### 3.3 Model Selection

Choose which AI models to use:
- **Main Model**: For architecture planning and reasoning
- **Code Model**: For code generation tasks

### 3.4 Pending Questions

When the AI needs clarification, questions will appear here:
- Click an option to answer
- The system shows what happens if you don't respond

### 3.5 Recent Artifacts

View assets generated by the AI:
- **Locate**: Find in FileSystem dock
- **Instantiate**: Add to current scene

---

## 4. Main Screen Guide

### 4.1 Plan Tree

The left panel shows your task DAG:
- Click tasks to view details
- Status indicators:
  - Pending (gray)
  - Waiting Approval (orange)
  - Running (blue)
  - Succeeded (green)
  - Failed (red)

### 4.2 Task Details

The right panel shows:
- Task information (ID, kind, status)
- Priority and risk level
- Success criteria
- Execution logs

### 4.3 Toolbar Actions

- **Regen**: Regenerate the plan
- **Run**: Execute selected task
- **Pause**: Pause execution
- **Export**: Export plan as JSON

---

## 5. Supervisor Modes

### 5.1 Shadow Mode

The AI only suggests actions but doesn't execute them automatically.  
**Best for:** New users, high-risk projects

### 5.2 Guardian Mode

Low-risk tasks run automatically, high-risk tasks require approval.  
**Best for:** Standard team workflow

### 5.3 Collaborative Mode

The AI asks for confirmation at each phase boundary.  
**Best for:** Architecture design, style decisions

---

## 6. Approval Workflow

### 6.1 When Approval is Required

The AI will ask for approval before:
- Overwriting existing files
- Modifying scene files (.tscn)
- Running shell commands
- High-cost operations (>500K tokens)

### 6.2 Approving Tasks

1. A notification will appear in the dock
2. Click **Approve** or **Reject**
3. The task will proceed based on your decision

---

## 7. Asset Management

### 7.1 Importing Assets

Generated assets are automatically imported to:
```
res://ai_generated/
├── ui/          # UI textures
├── sfx/         # Sound effects
├── scripts/     # GDScript files
└── scenes/      # Scene files
```

### 7.2 Instantiating Assets

1. Find the asset in Recent Artifacts
2. Click **Instantiate**
3. The asset will be added to your current scene

### 7.3 Rollback

To undo changes:
- Use Godot's built-in Undo (Ctrl+Z)
- Or click **Rollback** in the artifacts section

## 8. Best Practices

### 8.1 Writing Good Goals

Be specific and clear:
```
Good: "Create a 2D platformer character with double jump and attack"
Bad: "Make a character"
```

### 8.2 Managing Budget

- Start with a small budget for testing
- Monitor the budget bar
- Review costs before approving high-cost tasks

### 8.3 Version Control

Always commit generated assets to version control:
```git
git add res://ai_generated/
git commit -m "Add AI-generated assets"
```

### 8.4 Reviewing Output

Always review AI-generated code:
- Check for logic errors
- Ensure it follows your coding standards
- Test thoroughly before shipping

## 9. Troubleshooting

### 9.1 Gateway Connection Failed

- Ensure the gateway is running (`poetry run python main.py`)
- Check that port 7777 is not blocked
- Verify the URL in `gateway_client.gd`

### 9.2 Task Execution Failed

- Check the task logs in the Main Screen
- Verify your API key is correct
- Check budget limits

### 9.3 Assets Not Importing

- Ensure the asset format is supported
- Check the output path is correct
- Verify file permissions

### 9.4 Undo Not Working

- Make sure you're using the plugin's instantiate feature
- Godot's Undo/Redo only works for editor actions

1. **Start small**: Begin with simple tasks before complex ones
2. **Iterate**: Use the Regenerate button to refine plans
3. **Review**: Always check AI output before committing
4. **Collaborate**: Use the questions feature to involve team members
5. **Experiment**: Try different models to find what works best
